# 从 Windows 到 Ubuntu

面向 Windows 用户与技术开发者的 Ubuntu 24.04 LTS 交互式入门指南。

- [在线阅读](https://wuqi57good.github.io/ubuntu-beginner-dev-guide/)
- [下载离线包](https://wuqi57good.github.io/ubuntu-beginner-dev-guide/ubuntu-guide-offline.zip)

## 使用

在线访问上方网页，或下载离线包并解压后双击 `ubuntu-beginner-dev-guide.html`。

教程有 13 章、2 个附录和 6 个可重置交互沙盘。HTML、CSS、JavaScript 与 SVG 均内联，正文与交互不依赖外部请求。单文件 `index.html` 即可运行。

## 发布

GitHub Pages 从 main 分支根目录部署；`.nojekyll` 保持静态文件原样发布。更新 `index.html` 后，部署会自动重新运行。
